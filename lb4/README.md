Яйцо Мосса по двум радиусам:
- уравнение окружности;
- параметрическое уравнение;
- Брезенхем;
- встроенный метод.

R - радиус нижней дуги, r - верхней. Боковые дуги имеют радиус 2R.
При независимом выборе R и r получается обобщенное яйцо Мосса.
Начальные значения: R=90, r=53, X=190, Y=200. Требуется 5 <= r < R.
X и Y - центр нижней дуги на исходном изображении. Фигура должна помещаться целиком.

Запуск: python main.py
source.png открывается автоматически. Кнопкой Открыть можно выбрать другое изображение.
Введите центр и радиусы -> Построить -> PNG или PBM.
Вверху показано число различающихся пикселей относительно первого метода.
PBM сохраняется текстом в формате P1.
